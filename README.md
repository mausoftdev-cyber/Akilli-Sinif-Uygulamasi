# Akıllı Sınıf Uygulaması

Pardus ETAP etkileşimli tahtalar için geliştirilmiş ücretsiz sınıf yönetim uygulaması.

## Özellikler
- Öğrenci ve sınıf yönetimi
- Doğum günü hatırlatma ve kutlama
- Sınıf içi etkinlik yönetimi
- Etkileşimli tahta kişiselleştirme

## Kurulum
Uygulamanın .deb kurulum dosyasını Releases bölümünden indirebilirsiniz.
